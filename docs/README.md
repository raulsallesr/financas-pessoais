# Documentação do FocusLens BR

Este diretório separa decisão de produto, arquitetura, validação e material
de publicação. O [`README` principal](../README.md) continua sendo a entrada
para conhecer e executar o projeto.

## Onde encontrar cada assunto

- [`product/`](product/): plano canônico, estratégia e metodologias;
- [`architecture/`](architecture/): fronteiras implementadas e arquitetura
  institucional planejada;
- [`validation/`](validation/): roteiros de build, aparelho, carteira e B3;
- [`publication/`](publication/): release, auditoria e textos de LinkedIn;
- [`assets/`](assets/): capturas, diagramas, GIF e vídeo demonstrativo.
