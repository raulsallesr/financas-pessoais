# Issues com label "ideia" para o Raul escrever pelo celular
## Problema
Hoje o Raul só consegue dar uma ideia às IAs sentando num computador com uma sessão aberta.
## Proposta
Issue do GitHub com label `ideia`, criada pelo app do celular. O `equipe iniciar` leria as issues
abertas pela API pública (sem login e sem `gh`) e as listaria junto das ideias em arquivo.
## Custo e risco
Baixo. Em 2026-10-13 o Raul preferiu não usar Issues por ora; fica registrado como opção futura.
