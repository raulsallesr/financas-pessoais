# Lastro: uso pessoal, Python e Streamlit primeiro, fontes oficiais e gratuitas
## Decisão
O módulo Ativos B3 é de **uso pessoal do Raul**; o repositório público serve de portfólio
técnico. O motor é Python e a web é Streamlit primeiro; o mobile consome o mesmo resultado
depois. As fontes são oficiais e gratuitas (CVM Dados Abertos, COTAHIST da B3, BACEN e Tesouro).
A plataforma se chama **Lastro** (nome provisório) e o FocusLens vira o módulo Macro.
## Por quê
Rating, valor estimado e carteira para terceiros esbarram nas regras da CVM para analista e
consultor (Res. 19 e 20/2021). Streamlit permite iterar fórmula e rating rápido. Fonte oficial
evita custo, token e dependência de terceiros.
## Alternativas rejeitadas
Público geral com recomendação (exige analista credenciado). Direto no app mobile (iteração
lenta). API paga ou com token (custo e dependência).
